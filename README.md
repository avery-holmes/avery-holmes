## What I'm building

A React Native / TypeScript mobile application focused on caregiver coordination and day-to-day care tracking.

Current areas of work include:
- child-centered care workflows
- structured event logging
- activity history and care calendar experiences
- responsive phone and tablet layouts
- product architecture and maintainability
- planning for authentication, shared-care synchronization, testing, and security

The current version is an actively developed prototype and is not presented as a production healthcare platform.
